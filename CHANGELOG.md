# change log

## 3.0.0 — 2026-09-18
* Несовместимо: из модуля убран markdown-блок целиком — вкладка «Документация», ajax-контроллер Main\Options\Markdown, класс Options\Markdown\Option, параметр indexDoc у ShOptionsConfig::getInstance(), вендорённый vendor/Michelf (php-markdown и php-smartypants) и js-расширение install/js/shef-options/options-markdown. Документация живёт в репозитории, в поставке остаётся README как readme пакета
* Несовместимо: удалён каталог lib/main/oldoptions/ — 13 файлов объявляли те же FQCN, что и lib/main/options/, но лежали не там, где их ищет автозагрузка. Ядро брало options/, oldoptions/ не брал никто, а на портал каталог ехал
* Несовместимо: минимальная версия PHP — 8.2 (была 8.1). CI гоняет 8.2, 8.3, 8.4 и 8.5
* Constants::getSystemUserId() разбирает настройку строго: (int) превращал пустое значение в 0 («от имени никого»), а '5 62' — в 5, то есть в права пользователя, которого никто не выбирал. Всё, что не целое больше нуля, теперь даёт умолчание Constants::DEFAULT_SYSTEM_USER_ID
* Исправлен класс события в установщике: UnInstallEvents() создавал \Bitrix\Main\Entity\Event вместо \Bitrix\Main\Event, и удаление модуля падало с TypeError, если кто-то подписался на onModuleUnInstall
* Установщик убирает /bitrix/js/shef-options на порталах, обновившихся с версий до 3.0.0: записи в installDir для него больше нет
* CLAUDE.md больше не едет в поставку — это памятка по репозиторию, а не документ модуля
* Тесты: autoload_test.php (класс лежит там, где его ищет ядро; один FQCN — один файл), settings_test.php (ссылки из .settings.php никуда не висят), constants_test.php. assets_test.php переведён на общую обвязку
* build.sh: отсутствие node роняет сборку, если JS или *_test.mjs есть; run_tests сверяет число найденных тестов с числом прогнанных; сверка с git archive идёт по индексу и больше не пропускается на грязном дереве; символическая ссылка под контролем git роняет сборку; не-ASCII имена файлов больше не ломают проверки

## 2.4.0 — 2026-09-18
* Безопасность: ajax-загрузчик документации собирал путь из двух параметров запроса без проверки, и «../» в любом из них уводило чтение за каталог модуля. Путь разрешается в \Shef\Options\Main\Options\Markdown\DocumentPath и сверяется с каталогом модуля ПОСЛЕ разрешения — realpath раскрывает и «..», и символические ссылки
* Безопасность: действие getContent проверяет право на модуль. Спрятать вкладку мало — адрес действия виден в коде страницы
* Безопасность: \Shef\Options\Components\Actions\Normal задавал голый «prefilters» из одного HttpMethod, а этот ключ замещает умолчания ядра целиком — с действия снимались Authentication и Csrf. Теперь Normal — это ровно умолчания ядра
* Несовместимо: умолчание AControllerable::getConfigureActionsDefFilter() — Normal вместо Free. Раньше каждое ajax-действие наследника отвечало без входа на портал и без проверки csrf. Компоненту для гостей Free остаётся, но выбирается явно
* tests/documentpath_test.php — 30 проверок разбора пути, включая символическую ссылку наружу и нулевой байт

## 2.3.0 — 2026-09-18
* Модуль поставляется только в UTF-8. Перекодировка убрана из установщика, вместо неё в DoInstall() проверка кодировки проекта и отказ ставиться на портал в CP1251
* Исправлены короткие теги `<?` в def-functions.php и четырёх ainstaller.php: при short_open_tag=Off классы в них не определялись вовсе, а исходник уходил в браузер
* Возвращён параметр $stopSignal в \Shef\Options\Main\TempFile\Pid::removeByGroup, заявленный в 2.2.16, но в сборку не попавший
* Из UnInstallFiles() убрана проверка машины разработчика, из-за которой удаление файлов могло пропускаться, а на Linux сыпался warning
* Публичные пути фронта выведены в Constants::getPublicCssDir() и getPublicJsDir()
* Ссылки во вкладке «Документация» разбираются по схеме URL: документация переехала в репозиторий, и README ссылается на GitHub
* Исправлено чтение $options['str_replace'] без проверки в TraitList\Tools\PrepareFields::translit — на PHP 8 каждый вызов без этого ключа давал warning
* Возвращён declare(strict_types=1) в 14 файлах, потерянный в сборке 2.2.16
* composer.json: пакет bxshef/options, тип bitrix-module с extra.installer-name, лицензия MIT
* Документация модуля вынесена из поставки в репозиторий
