# Новая опция настроек

Операция: добавить одну настройку — от описания до чтения в коде. Устройство
страницы целиком — в skill `shef-options-settings`, здесь порядок действий.

## 1. Выбрать тип

Все в namespace `\Shef\Options\Main\Options`:

| надо | класс |
|---|---|
| строка | `Text` |
| большой текст | `TextArea` |
| да/нет | `Checkbox` (хранится Y/N) |
| целое / дробное | `NumberInt` / `NumberFloat` |
| свой список | `Enum` + `setList()` |
| пользователь | `Users` |
| сотрудники и отделы | `Department` (результат в json) |
| инфоблок | `EnumIblock` |
| highload-блок | `EnumHl` |
| единица измерения | `EnumMeasure` |
| ставка НДС | `EnumVat` |
| валюта | `EnumCurrency` |
| тип цены | `EnumPriceType` |
| направление сделки | `EnumCrmDealCategory` |
| справочник источников | `EnumCrmSource` |
| тип смарт-процесса | `EnumCrmSmartProcessType` |
| пресет реквизитов | `EnumCrmRqPreset` |
| не опция, а сообщение | `RowInfo` + `setType(TypeUIAlert::Warning)` |

Своего списка, которого тут нет, обычно и не надо: `Enum` закрывает остальное.

## 2. Объявить в `options_conf.php`

```php
$options->addTab(
    (new Options\Tab('DEF'))
        ->setName(Loc::getMessage($options->moduleId.'_TAB_DEF_NAME'))
        ->setTitle(Loc::getMessage($options->moduleId.'_TAB_DEF_TITLE'))
        ->addOption(
            (new Options\Text('apikey'))
                ->setTitle(Loc::getMessage($options->moduleId.'_TAB_DEF_apikey'))
                ->setDescription(Loc::getMessage($options->moduleId.'_TAB_DEF_apikey_descr'))
                ->setDefValue('')
        )
);
```

## 3. Понять, как будет называться настройка

Имя собирается как **`<код вкладки>_<код опции>`** —
`\Shef\Options\Main\Options\AOption::getComplexCode()`. Вкладка `DEF` плюс
опция `apikey` дают настройку `DEF_apikey`.

Из этого следуют два правила:

* **код вкладки менять нельзя.** Переименовали `DEF` в `MAIN` — все
  сохранённые значения стали недоступны, хотя в базе лежат под старым именем.
  Меняете — пишите миграцию в `DoInstall()`;
* **код опции — идентификатор, а не подпись.** Подпись живёт в языковом файле,
  код остаётся навсегда.

## 4. Подписи

Ключ собирается из идентификатора модуля, точка в нём — часть ключа:

```php
// lang/ru/options_conf.php
$MESS['shef.demo_TAB_DEF_apikey'] = 'Ключ API';
$MESS['shef.demo_TAB_DEF_apikey_descr'] = 'Выдаётся в личном кабинете поставщика';
```

## 5. Прочитать значение в коде — и вот здесь осторожно

```php
// НЕ НАДО
$userId = (int)Option::get('shef.demo', 'DEF_userid');
```

Значение приходит из формы строкой, и приведение типом на нём ошибается
молча:

| в настройке | `(int)` | что это значит на деле |
|---|---|---|
| `''` (очистили поле) | `0` | работа «от имени никого» |
| `'5 62'` (опечатка) | `5` | права пользователя, которого никто не выбирал |
| `'05'` | `5` | то же самое |

Ни одного предупреждения в логе. Разбирайте строго: целое больше нуля либо
строка из одних цифр, иначе умолчание. Готовый разбор для служебного
пользователя — `\Shef\Options\Main\Constants::getSystemUserId()`, для полей
вообще — трейт `\Shef\Options\TraitList\Tools\PrepareFields`.

Для `Checkbox` сравнивайте с `'Y'`, а не приводите к `bool`: строка `'N'`
приводится к `true`.

Для `Department` в настройке лежит **json** — разбирайте `Json::decode()`, и
отличайте «настройка пуста» от «настройка задана, но не разбирается»: это
разные случаи, и вести себя они должны по-разному.

## 6. Проверка

1. Опция появилась на странице, подпись и описание по-русски.
2. Заполнить, сохранить, перезайти — значение на месте.
3. **Очистить поле, сохранить** — код, который его читает, не падает и не
   начинает работать от нуля.
4. Вписать заведомый мусор — тот же ответ: умолчание, а не половина значения.
