# Навыки линейки shef.*

Каталог-источник — [bx-shef/options](https://github.com/bx-shef/options),
`.claude/skills/`. В остальные репозитории линейки навыки **раскладываются**
скриптом, а не копируются руками.

## Что здесь есть

Справочные — «как устроено»:

| навык | о чём |
|---|---|
| `shef-options-blocks` | синглетон, реестр настроек, объект из массива, pid-блокировка |
| `shef-options-traits` | восемнадцать трейтов: что даёт, когда брать |
| `shef-options-components` | `AComponent`, ajax, `Builder`, фильтры прав |
| `shef-options-settings` | страница настроек на `ShOptionsConfig` |
| `shef-options-installer` | установка смарт-процессов, UF и пресетов |

Операционные — «сделай по канону»:

| навык | что делает |
|---|---|
| `shef-new-module` | скелет нового модуля линейки |
| `shef-new-component` | компонент на `AComponent` |
| `shef-new-ajax-action` | ajax-действие с правильными фильтрами |
| `shef-new-option` | опция на страницу настроек |
| `shef-new-agent` | агент или cron с блокировкой |

Разница в том, как их берут. Справочный навык агент подхватывает сам, когда
угадывает тему. Операционный вызывают явно: `/shef-new-agent` — «сделай мне
агента по канону».

## Синхронизация

```bash
.claude/skills/sync.sh --manifest          # пересобрать MANIFEST (в источнике)
.claude/skills/sync.sh --to ../shef.demo   # разложить в соседний репозиторий
.claude/skills/sync.sh --check             # целостность копии
.claude/skills/sync.sh --check <источник>  # сверка с источником (путь или URL)
```

`MANIFEST` — список sha256 всех файлов каталога, включая сам `sync.sh`. Копия
несёт его с собой, поэтому проверяться умеет без сети, а с сетью — ещё и
сверяться с источником.

**Правят навыки только в источнике.** Правка копии на месте будет затёрта
следующей раскладкой, а до неё — поймана проверкой.

## Что добавить в CI получателя

```yaml
- name: Навыки не отстали от источника
  run: .claude/skills/sync.sh --check https://raw.githubusercontent.com/bx-shef/options/main/.claude/skills/MANIFEST
```

Без сети достаточно `--check` без аргумента: он поймает правку копии, но не
заметит, что источник ушёл вперёд.

## Почему это не просто «скопировать папку»

Навык врёт молча. Класс переименовали, а в тексте осталось старое имя —
ошибки нет, текст выглядит убедительно, и агент уверенно повторит. У копии,
отставшей на три месяца, ровно та же болезнь, только хуже: в источнике всё
уже поправлено.

Поэтому в источнике содержимое навыков проверяется тестом — каждый класс,
названный в навыке, обязан существовать в дереве `lib/`, — а у получателя
проверяется, что его копия и есть источник.

## Если правите навык

1. правка в источнике;
2. `.claude/skills/sync.sh --manifest`;
3. `./build.sh --check` — `tests/skills_test.php` не пропустит несобранный
   манифест, а `tests/docs_test.php` не пропустит несуществующий класс;
4. раскладка по репозиториям: `sync.sh --to <путь>` для каждого.
