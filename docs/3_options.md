# [`Shef\Options\Main\Option`] Опции настроек модуля

Поддерживает следующие типы:

|                          Класс | Описание                                                                                                      |
|-------------------------------:|:--------------------------------------------------------------------------------------------------------------|
|      (enum) Option\TypeUIAlert | Перечисление типов сообщений.<br/>Используется для определения как выводить сообщение                         |
|                 Option\RowInfo | Для вывода строки с сообщеним, поддерживает BBCODE                                                            |
|                    Option\Text | Для работы со строками                                                                                        |
|                Option\TextArea | Для работы со большим текстом                                                                                 |
|                Option\Checkbox | Для работы с логическим выбором, Y/N                                                                          |
|               Option\NumberInt | Для работы с целыми числами                                                                                   |
|             Option\NumberFloat | Для работы с дробными числами                                                                                 |
|                    Option\Enum | Для работы с перечислениями                                                                                   |
|                   Option\Users | Для работы со списком пользователей, поддерживает фильтрацию                                                  |
|              Option\Department | Подбор сотрудников и отделов используя `ui.entity-selector` модуля intranet.<br/>Результат сохраняется в json |
|                  Option\EnumHl | Для работы со списком HL, поддерживает фильтрацию                                                             |
|              Option\EnumIblock | Для работы со списком инфоблоков, поддерживает фильтрацию                                                     |
|             Option\EnumMeasure | Для работы со списком единиц измерения, поддерживает фильтрацию                                               |
|                 Option\EnumVat | Для работы со списком ставок НДС, поддерживает фильтрацию                                                     |
|            Option\EnumCurrency | Для работы со списком валют, поддерживает фильтрацию                                                          |
|           Option\EnumPriceType | Для работы со списком типов цен, поддерживает фильтрацию                                                      |
|     Option\EnumCrmDealCategory | Для работы со списком направлений сделок, поддерживает фильтрацию                                             |
|           Option\EnumCrmSource | Для работы со списком из справочника, поддерживает фильтрацию                                                 |
| Option\EnumCrmSmartProcessType | Для работы со списком типов смарт-процессов, поддерживает фильтрацию                                          |
|         Option\EnumCrmRqPreset | Для работы со списком пресетов реквизитов, поддерживает фильтрацию                                            |
